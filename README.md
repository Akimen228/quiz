# Викторина - Web-приложение для тестирования

Локальное веб-приложение для проведения тестов из `.txt` файлов.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload
```

Откройте в браузере: http://127.0.0.1:8000

## Формат файла с вопросами

Вопросы в `.txt` файле должны быть в следующем формате:

```text
Текст вопроса
=====
#Правильный ответ
=====
Неправильный ответ 1
=====
Неправильный ответ 2
=====
Неправильный ответ 3
=====
Неправильный ответ 4
+++++

Следующий вопрос
=====
Неправильный ответ 1
=====
#Правильный ответ
=====
Неправильный ответ 2
=====
Неправильный ответ 3
++++
```

### Правила формата:

- Каждый вопрос начинается с текста вопроса
- Варианты ответов разделяются символами `=====` или `====`
- Правильный ответ помечается символом `#` в начале
- Вопросы разделяются строкой из `++++` или `+++++` и более плюсов
- Допускается ровно 4 или 5 вариантов ответа
- Должен быть ровно 1 правильный ответ
- Старые файлы с 4 вариантами ответа остаются совместимыми

## Возможности

- Загрузка вопросов из `.txt` файла
- Случайное перемешивание вопросов и вариантов ответов
- Мгновенная обратная связь после ответа
- Подсветка правильного и неправильного ответа
- Показ итогов с процентом правильных ответов
- Список ошибок с указанием правильных ответов
- Возможность пройти тест заново
