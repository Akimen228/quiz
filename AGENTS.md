# AGENTS.md — Викторина (web quiz)

Контекст для AI-агентов, работающих в этом репозитории.

## Что это
Веб-приложение «Викторина»: пользователь проходит тесты с вариантами ответов.
Раздаётся как **статический сайт на GitHub Pages** из папки `docs/`.

## Стек и принципиальные ограничения
- **Чистая статика**: ванильный HTML + CSS + JavaScript. Никаких фреймворков,
  бандлеров, npm-зависимостей, внешних CDN. Сайт обязан работать на GitHub Pages
  **без сервера**. Библиотека готовых тестов читается через `fetch(manifest.json)`,
  поэтому требует HTTP (GitHub Pages или локальный `python -m http.server`). При
  открытии `index.html` как `file://` готовый список недоступен (ограничение
  браузера на fetch локальных файлов) — это ожидаемо; загрузка своего `.txt`
  через `FileReader` при этом работает.
- **Никакого рантайм-Python в браузере.** Python используется только для
  вспомогательных build-скриптов (генерация `manifest.json`) и для legacy-кода.
- Кодировка везде **UTF-8**, обязательна корректная поддержка **кириллицы**.

## Раскладка
- `docs/` — то, что публикуется (index.html, style.css, script.js, tests/, manifest.json).
- `docs/tests/*.txt` — банк тестов, **коммитится** (его видят все пользователи).
- `parser.py`, `main.py`, `templates/`, `static/`, `Dockerfile` — **legacy** FastAPI-версия.
  Оставлена как история, **для хостинга не используется**. Не развивать без явной просьбы.

## Инварианты (не нарушать)
1. **Парсер `.txt` в `docs/script.js`** должен давать результат, идентичный
   эталонному `parser.py`. Формат теста:
   - варианты ответа разделяются строкой из 4+ знаков `=`;
   - вопросы разделяются строкой из 4+ знаков `+`;
   - правильный ответ помечен `#` в начале;
   - ровно 4 или 5 вариантов, ровно 1 правильный;
   - поддержка кодировок входного файла: UTF-8 (в т.ч. BOM), UTF-16 LE/BE, Windows-1251.
2. Не ломать существующий поток теста (перемешивание Fisher–Yates, подсветка,
   экран результатов, «пройти ошибки заново»).
3. **Личные файлы вопросов в корне** (`вопросы*.txt`, `ответы.txt`) — приватные,
   они в `.gitignore`. Не коммитить их и не копировать в `docs/`.
4. Пути к ресурсам в `docs/` — **относительные** (`style.css`, не `/static/...`),
   иначе ломается на GitHub Pages в подкаталоге `<user>.github.io/<repo>/`.

## Проверка
- Логику парсера/манифеста — Python/Node-скриптами.
- Сайт — локально: `cd docs && python -m http.server 8123`, открыть `http://127.0.0.1:8123`.
- Нет линтера/тест-раннера по умолчанию; добавляешь поведение — добавь и проверку.
