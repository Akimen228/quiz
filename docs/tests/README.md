# Банк тестов

Положите новый `.txt` файл в эту папку и сделайте `git push`. GitHub Actions
перегенерирует `docs/manifest.json`, и тест появится в списке на сайте.

Рекомендуется давать файлам латинские имена без пробелов, например
`biology_8_class.txt`. Кириллица в именах файлов тоже поддерживается.

## Формат вопроса

```text
Текст вопроса
=====
#Правильный ответ
=====
Неправильный ответ
=====
Неправильный ответ
=====
Неправильный ответ
++++
Следующий вопрос
```

- варианты ответа разделяются строкой из 4 или более знаков `=`;
- вопросы разделяются строкой из 4 или более знаков `+`;
- правильный ответ начинается с `#`;
- у каждого вопроса должно быть ровно 4 или 5 вариантов и ровно 1 правильный.
